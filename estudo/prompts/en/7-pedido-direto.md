# 7. The direct request (for anyone who wants to get started right away, in chat)

It’s the shortest way: four sentences. Attach the source materials. Then ask, “turn this into a web page.”
Even so, it’s worth planning first (prompt 1): that’s where you avoid having to redo everything later.

---

I want to create an interactive study guide for [name], who is studying [subject and level], based on how the teacher teaches and on what [name] has gotten wrong so far (attached material). [Name] needs to be able to choose the topics they want to study and create a personal study plan before the test. I want to be able to create summary sheets that [name] can customize and take along. Use only the attached material, and ask me if anything is missing.
